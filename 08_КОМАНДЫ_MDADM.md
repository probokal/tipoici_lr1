# Приложение. Основные команды mdadm (Kali Linux)

Составлено для сдачи отдельным списком и для работы при восстановлении массива.
В отчёт по ЛР1 этот список не вставлять: Травкин запрещает консольные команды в тексте отчёта, они и так видны на скриншотах.

## Опасность в исходной формулировке

Исходная команда `mdadm --create /dev/md0 --level=raid0 --raid-devices=2 /dev/sda /dev/sdb` в лабораторной на живой системе **разрушительна**: `/dev/sda` — это системный диск Kali (в твоём случае на нём корень), создание RAID поверх него уничтожит систему. В работе массив собирается **из образов**, а не из физических дисков. Правильно — подключить образы как блочные устройства через циклы (`losetup`) или монтировать E01 через `ewfmount` и собирать массив из полученных файлов-устройств.

## Справка и осмотр

| Команда | Что даёт |
|---|---|
| `mdadm --help` | краткая справка по утилите |
| `mdadm --version` | версия (в отчёте — 4.6-3) |
| `cat /proc/mdstat` | состояние всех массивов и процесс сборки |
| `lsblk -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINT` | все накопители и точки монтирования |

## Работа с образами (то, что реально нужно в ЛР)

| Команда | Что даёт |
|---|---|
| `ewfmount LAB1-DISK1.E01 /mnt/e01` | подключить EWF как файл `ewf1` в каталоге монтирования |
| `mmls /mnt/e01/ewf1` | таблица разделов: смещение и размер каждого тома |
| `fsstat -o <смещение> /mnt/e01/ewf1` | параметры файловой системы, размер кластера |
| `losetup -fP --show /mnt/e01/ewf1` | подключить образ как блочное устройство `/dev/loopN` с разделами |
| `losetup -d /dev/loopN` | отключить устройство после работы |

## Создание массива

```
mdadm --create /dev/md0 --level=5 --raid-devices=4 /dev/loop0 /dev/loop1 /dev/loop2 /dev/loop3
```

| Параметр | Значение |
|---|---|
| `--create /dev/md0` | создать новый массив с именем md0 |
| `--level` | уровень RAID: 0, 1, 5, 6, 10 |
| `--raid-devices` | число устройств в массиве |
| `--chunk` | размер блока чередования (по умолчанию 512 КБ) |
| `--assume-clean` | не пересчитывать чётность; применять только когда известно, что массив был чистым, иначе данные будут «считать» неверно |
| `--run` | запустить массив, если он собран не полностью |

## Осмотр и обслуживание

| Команда | Что даёт |
|---|---|
| `mdadm --detail /dev/md0` | уровень, состояние, размер, число устройств, UUID |
| `mdadm --detail --scan` | все массивы в формате для конфигурационного файла |
| `mdadm --examine /dev/loop0` | суперблок конкретного устройства: уровень, размер, номер диска |
| `mdadm --examine --scan` | сводка по всем устройствам, из которых можно собрать массив |

## Сборка существующего массива

| Команда | Что даёт |
|---|---|
| `mdadm --assemble /dev/md0 /dev/loop0 /dev/loop1 /dev/loop2 /dev/loop3` | собрать массив из перечисленных устройств |
| `mdadm --assemble --scan` | собрать все массивы, найденные на устройствах |
| `mdadm --assemble --run --force /dev/md0 /dev/loop0 /dev/loop1` | принудительная сборка неполного массива |
| `mdadm --stop /dev/md0` | остановить массив |
| `mdadm --zero-superblock /dev/loop0` | стереть суперблок (только когда массив уже не нужен) |

## Работа с отказавшими устройствами

| Команда | Что даёт |
|---|---|
| `mdadm /dev/md0 --fail /dev/loop1` | пометить устройство как отказавшее |
| `mdadm /dev/md0 --remove /dev/loop1` | извлечь его из массива |
| `mdadm /dev/md0 --add /dev/loop4` | добавить замену, начнётся восстановление |
| `mdadm --grow /dev/md0 --raid-devices=5` | расширить массив |

## Монтирование и проверка

| Команда | Что даёт |
|---|---|
| `mount /dev/md0 /mnt/raid` | смонтировать массив |
| `df -h /mnt/raid` | фактический размер и заполнение тома |
| `umount /mnt/raid` | размонтировать |

## Правило фиксации результата

Любая команда, меняющая массив (`--create`, `--assemble`, `--grow`, `--fail`), выполняется только после того, как зафиксированы исходные данные: `mdadm --examine` по каждому устройству и `md5sum` образов. Иначе при ошибке уровень и раскладка массива восстанавливаются угадыванием.
