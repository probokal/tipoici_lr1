# Требования к отчётам и шаблон (для ЛР1 и всех следующих)

Документ-память: чтобы каждую следующую лабораторную собирать сразу правильно, без переделок.

## 1. Обязательные элементы отчёта

1. Титульный лист.
2. Цель и задачи лабораторной работы.
3. Аппаратное обеспечение — технические характеристики использованных средств вычислительной техники.
4. Программное обеспечение — с указанием версий.
5. Описание результатов, полученных в ходе выполнения работы.
6. Вывод.

Формат файла — MS Office Word 2007+ (`.docx`). Имя: `Фамилия И.О._ Группа_Отчет_лаб_№N`.

## 2. Оформление текста

| Параметр | Значение |
|---|---|
| Шрифт | Times New Roman |
| Размер основного текста | 14 пт |
| Межстрочный интервал | 1,5 |
| Выравнивание основного текста | по ширине |
| Размер подписей к таблицам и иллюстрациям | 12 пт |
| Подписи к рисункам | под рисунком, по центру, сквозная нумерация |
| Подписи к таблицам | над таблицей, по правому краю |
| Заголовки | полужирным |

## 3. Иллюстрации

- Лаконичные, только необходимая информация, легко читаемые.
- Выделяются тонкой чёрной рамкой.
- Области интереса выделяются разноцветными прямоугольными рамками.
- Подпись кратко описывает наблюдаемый результат, а не процесс его получения.
- После подписи ставится точка.

## 4. Стиль изложения (требования Травкина)

| Нельзя | Можно |
|---|---|
| Консольные команды в тексте | «Были получены сведения о …» |
| «при помощи консольной команды …» | «по результатам выполнения получено …» |
| «Результат выглядит следующим образом» перед рисунком | рисунок просто вставляется по месту |
| Подробный пересказ каждого элемента скриншота | «на рисунке представлено …» |
| Подпись без точки | подпись с точкой |
| Рисунок без рамки, без выделений | тонкая чёрная рамка + цветные прямоугольники |

## 5. Шаблон титульного листа

```
Министерство науки и высшего образования Российской Федерации
Федеральное государственное бюджетное образовательное учреждение
высшего образования
«Московский государственный технический университет
имени Н.Э. Баумана (национальный исследовательский университет)»

ОТЧЕТ
по лабораторной работе №<N>
«<Название работы>»
по дисциплине
«Теоретические и практические основы исследования цифровой информации»

Выполнил: Миронов Б. А.
Группа: ЮР-73
Проверил: Травкин К. А.
Работа выполнена: <дата>
Отчёт сдан: <дата>
Оценка: ____________

Москва, 2026
```

## 6. Критерии оценки

1. Оформление.
2. Полнота — выполнены все задания работы.
3. Полученный результат — правильность выполнения.
4. Уровень знаний по тематике (защита).

## 7. Порядок сдачи

1. Оценка отчёта преподавателем.
2. Оценка знаний по тематике работы.
3. Отчёт — на электронном и бумажном носителе.
